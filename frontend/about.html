FLAREWATCH
Zero-Dependency High-Throughput SIEM & Threat Detection Engine

FlareWatch is a high-performance, zero-dependency SIEM system that ingests raw network logs, detects threats in real time using a hand-rolled Aho-Corasick engine, indexes logs for fast search, and streams live telemetry to this dashboard.
